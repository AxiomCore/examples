# UI feature gallery

Small Acore source examples for styles, layout, paint, text, animation,
elements, scrolling, input, overlays, and reusable components. Each numbered
directory is independent; start with its `main.acore`. Target-specific companion
files show platform variants.

These are authored source fixtures, not a prebuilt application. They require a
CLI/runtime with the relevant UI capabilities. No generated bundles, private
host code, or acceptance reports are included.
